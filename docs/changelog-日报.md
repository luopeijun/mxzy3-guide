## 2026-11-07（32 提交）· 打地基

尚未发版，全部为 v1.0.0 的前置工作。

- **项目初始化**：Vite + React 19 + TypeScript + Tailwind v4 脚手架，基础 UI 组件与样式令牌（`@theme` 令牌、`patterns.ts` 配方、`cn()` 工具）。
- **攻略数据管线**：`sources/*.txt` → `scripts/extract_guide.py` → `public/data/guide.json`，前端运行时加载（改内容不必重新打包）。
- **分层浏览页**（`#/guide`）：左侧类目/章节侧栏 + 右侧便签式事件卡渲染（编号、类型标签、CG 徽标、备注内链）。
- **解析规则**：`★` 为 section、`☆` 按层级当 heading、编号行转标签、子事件 `－` 栈算法嵌套、CG 行转粉底卡 + 金徽标。

## 2026-11-11（22 提交）· 追踪器多艺人 + 六大通告起步

尚未发版，合并进 v1.5.0。

- **追踪器多艺人追踪**：一个周目累计追踪 5+ 艺人（签约 → 解约 → 复签）。
  - `selectedArtists`（旗下 ≤4）+ 新增 `releasedArtists`（不限）两数组，`artistRoster()` 派生带状态位视图，`normaliseArtists()` 保证互斥。
  - 解约只改状态位，线与已打勾不动；失效线打 `staleKind`（`released` / `former-branch`）+ 灰标签，完成度默认不计入、可用「包含已解约」开关打开。
  - 路欧桑分支只读旗下 4 人、不读追踪名单；解约换人后旧分支线保留在池里（`retainedBranches` 留进度）。
  - 艺人入口为长条按钮块，解约/复签角标在整按钮右上角；满 4 时点未追踪按钮自动记为已解约 + 一行提示。
  - 所有导入统一在 `importProgress` 里补 `normaliseArtists()`（老存档不经 `sanitiseData`，否则覆盖导入会静默失效）。
- **六大通告看板起步**：审校条件表 → `sources/special-notices.tsv` → `scripts/extract_specials.py` → `public/data/specials.json`；领域类型 + 状态评估 + 卡片骨架，条件行压成单行、证书课程等级点选、集中「数值录入」面板。
